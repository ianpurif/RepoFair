# Independent provider boundary
RepoFair's configured provider runtime serves owner-approved signed source through Tempo Moderato testnet. Keep its identity, source, database, issuer public key, recipient and MPP secret separate from the web application. Preparation and fixture entries remain isolated from the configured runtime. Read docs/PROVIDER-PUBLISHING.md and TEMPO.md. Never turn a transaction hash into proof without authoritative verification. Validate access/version before charging; persist paid delivery recovery. No fixture receipt masquerades as actual settlement.
