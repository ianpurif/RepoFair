# Original source fixtures

These small authored examples are not real customers, upstream maintainers, or published npm packages. Do not install arbitrary source during ingestion.

jobboard-app uses local file-linked retry-kit 1.0.0 and event-log 1.0.0. Its package-lock is generated by npm in package-lock-only/ignore-scripts/offline mode; it records local dependency versions, not live npm installations. Retry-kit 2.0.0 is a separate supported provider snapshot with a permanent-error behavior change.

`catalog.json` contains actual content digests, not fabricated Git commits. Derive the graph from original source with ts-morph during P1. Expected files in questions.json are reviewed fixture evidence targets, not precomputed answers or graph output.

Provider service boundaries can run as fixture-retry on port 4311 and fixture-events on 4312. They return unavailable for context/payment/MCP until implementation. Recipients are not prefilled. Testnet evidence requires actual separately configured accounts and real transactions.
