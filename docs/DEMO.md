# Fixture demonstration

Run `bun run dev`, `bun run provider:a`, and `bun run provider:b` in separate terminals. Open http://localhost:3000/demo.

1. Select jobboard-app 1.0.0. Its graph is parsed from digest-checked source.
2. Ask: “How does this application retry failed jobs, and what could be affected by changing that behavior?” Inspect citations and missing dependency evidence.
3. Select the two fixture providers. Review the separate external question before approving. Buyer source and the local prompt are not sent.
4. Retrieve context through two actual HTTP processes. Inspect provider source and the fixture/no-payment label.
5. Switch to jobboard-app 2.0.0. Old evidence becomes inapplicable. Approve fresh retrieval; retry-kit 2.0.0 now excludes permanent errors.
6. Ask about retry-kit 9.0.0 or proof no production job ever fails. Inspect explicit abstention.
7. Stop a provider and refresh discovery. No purchase retry or settlement confirmation is invented.

These are original examples, not customers or public npm releases. Real Tempo testnet demonstration remains blocked on approved configuration and receipts.
